# ADR-004. Whiteboard System Design: Excalidraw + палитра блоков

**Статус:** принято (2026-09-09)

## Контекст
Стадия System Design (FR-S5, US-5): палитра 12 архитектурных блоков, соединения, свободное
рисование, заметки; ИИ оценивает схему (vision) + устный ответ; схема сохраняется в истории
сесси (FR-A4). Формат — «блоки + рисование» (решение #10).

## Решение
- **Холст** — [Excalidraw](https://github.com/excalidraw/excalidraw) (MIT), React-компонент
  внутри SPA (фаза WP-10). Свободное рисование/стрелки/текст — нативные инструменты.
- **Палитра 12 блоков** — шаблоны-группы элементов Excalidraw (иконка + подпись):
  Client, Load Balancer, API-сервис, Worker, SQL-БД, NoSQL, Кэш, Очередь, Message Broker,
  CDN, Внешний API, Monitoring. Вставка — клик (генерация элементов в точке), перетаскивание —
  нативное; соединения — стандартные стрелки Excalidraw (примагничивание к краям групп).
- **Состояние** — JSON холста (`elements` + `appState`) сохраняется на бэкенд с debounce
  2 с и по выходу со стадии (`PUT /api/v1/sessions/{id}/whiteboard`).
- **Экспорт для оценки** — PNG (Excalidraw → canvas, по широкой стороне ≥ 1920 px) + структурированный
  список блоков/связей, извлечённый из JSON (детерминированная семантика).
- **Оценка ИИ** — Qwen vision (PNG) + семантический анализ структуры по рубрике
  (покрытие: клиент/LB/сервисы/БД/кэш/очереди/мониторинг; масштабируемость; отказоустойчивость;
  обоснование trade-offs) + транскрипт устного ответа стадии → балл в отчёт (SRS v1.1, §12).

## Альтернативы
- **Собственный canvas**: полный контроль, но 3–4× срок разработки без пользы. Отклонено.
- **draw.io embed**: тяжёлый, слабое программное API для извлечения структуры, вопросы
  к лицензии в проде. Отклонено.
- **Только текст/структурная форма**: отклонено — формат утверждён пользователем (решение #10).

## Последствия
- + Быстрый старт (библиотека зрелая: undo, экспорт, тёмная тема), MIT — лицензионно чисто (NFR-10).
- + Двойная основа оценки (картинка + структура) — устойчивость к «кривому рисунку».
- − Бандл Excalidraw ≈ 200–400 kB gz — принимается (SPA, один раз).
- − Качество PNG зависит от масштаба холста — нормировка экспорта (1920 px+).
