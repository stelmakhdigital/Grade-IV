# BUG-20261014-024 — Вывод тестов Live-Code: стена сырого JSON вместо диагностики

**Симптом.** «Запустить тесты» → блок run-output показывал 2 строки имён тестов и
затем поток машинного JSON go test -json (`{"Time":...,"Action":"run",...}`) —
диагностика проваленных тестов (t.Logf) терялась в стене текста.

**Причина.** Контракт sandbox не наполняет per-test output; api отдаёт stdout
как есть; панель рендерила сырой stdout. Парсинга go test -json не было.

**Фикс.** Frontend-парсер `goTestDigest.ts`: per-test статусы + диагностические
строки (=== RUN/--- FAIL отфильтрованы), сводка пакетов, сырой вывод — под
спойлером «сырой вывод тестов». Не-json вывод (pytest, ошибки компиляции) —
как раньше. per-test output из контракта api (если появится) приоритетнее.

**Проверено.** f03-livecode-run.png (после): «✗ TestPubSubDelivery /
solution_test.go:23: ch1 = "", want "hello"» и т.д.; vitest 118 ok.
