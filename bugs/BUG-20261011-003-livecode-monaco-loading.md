# BUG-20261011-003 · Live-Code: загрузка Monaco — только текст, без спиннера/скелетона

- **Статус:** исправлено
- **Область:** `services/frontend/src/views/livecode/CodeEditor.tsx`, `src/index.css`

## Симптом
При ленивой загрузке Monaco (CDN, `@monaco-editor/react`) в месте редактора показывается
голый текст «Загрузка редактора…» на пустом фоне — нет обратной связи о загрузке
(спиннер/скелетон), высота не зафиксирована → layout shift при появлении редактора.

## Исправление
Заменён `loading`-проп на скелетон: фиксированная высота (320px, как у редактора),
тёмный фон, спиннер + текст. `role="status"`/`aria-label` для доступности. CSS
`.code-loading` / `.code-loading-spinner`.

## Замечание
Monaco грузится с CDN (предсуществующий дизайн). Вне сети спиннер/скелетон показывается,
но редактор не поднимется — это ограничение CDN, не этой правки.
