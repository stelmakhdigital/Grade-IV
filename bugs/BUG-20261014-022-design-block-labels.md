# BUG-20261014-022 — Блоки System Design на живом холсте без подписей

**Симптом.** Клик по блоку палитры («Client», «Load Balancer», …) ставил на холст
Excalidraw пустой цветной прямоугольник — подписи нет. При этом экспортный PNG
(«Оценить схему» → vision-ревью) подписи содержал: ИИ знал имена блоков
(дополнительно им передаются текстом в structure.blocks), но кандидат на живом
холсте не видел, какой блок где.

**Шаги.** Сессия middle/go → Live-Code → «К System Design» → клик «Client» →
прямоугольник без текста. Скриншоты: /tmp/ux-audit/shots-func/f04-design-blocks.png (до).

**Причина.** Элементы сцены строились вручную (rect + standalone text,
containerId: null) и вставлялись голым `api.updateScene()` — живой рендерер
Excalidraw 0.18 такие текст-элементы не отрисовывает (экспорт через
exportToBlob рисует — путь экспорта не зависит от нормализации сцены).

**Фикс.** Каноничный «labeled rectangle»: text с containerId=rectId +
rect.boundElements=[{id: textId}]; вставка сцены через модульный
`restoreElements(...)` (нормализация: шрифты текста, связи, fractional-индексы)
+ updateScene. placeBlock сериализован очередью (быстрые клики не теряют блоки).
Сетка блоков теперь адаптивная (колонки от appState.width — на мобильном блоки
не обрезаются краем холста).

**Проверено.** labels-live.png: Client/Load Balancer/CDN с подписями; мобильный
скрин (m2) — блоки в одну колонку, обе подписи видны; vitest 118 ok; tsc ok.
