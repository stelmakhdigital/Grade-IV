# BUG-20261011-004 · Live-Code: «большой файл» — обманчивая ошибка 400 вместо 413

- **Статус:** исправлено
- **Область:** `services/api/internal/httpapi/runs_handlers.go`

## Симптом
POST /runs с исходниками > 1 МБ (лимит `runsMaxBodyBytes`) возвращал
`400 invalid_request «ожидается JSON {files, action, task_id}»` — сообщение о формате
тела, а не о превышении размера. Кандидат не понимает, что файл слишком большой.

## Корень
`http.MaxBytesReader` при превышении лимита обрывает чтение, `json.Decode` падает с
`*http.MaxBytesError`, но обработчик сворачивал любую ошибку декодирования в
`400 «ожидается JSON»`.

## Исправление
Выделен случай `*http.MaxBytesError` → `413 too_large «исходники слишком большие
(лимит 1 МБ)»`; остальные ошибки декодирования остаются `400 invalid_request`.

Регресс: api `go test ./...` зелёный; тесты не менялись.
