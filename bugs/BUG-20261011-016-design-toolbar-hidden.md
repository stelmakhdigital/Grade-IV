# BUG-20261011-016 — System Design: тулбар сокрыт за гигантским логотипом-триггером

**Статус:** исправлено (коммит с этим документом)
**Совместно с:** UX-проход System Design (палитра, «Очистить холст», статусы оценки)

## Симптом

В секции System Design на холсте вместо тулбара инструментов виден огромный
логотип Excalidraw (≈768×768) и английские подсказки. Инструмент «Стрелка»
(и все остальные) кандидат не видит — кликнуть, чтобы нарисовать связь,
нечего. На всех QA-сессиях схемы не имели связей (`links=0`) при наличии
блоков.

## Шаги воспроизведения

1. Открыть сессию middle+, дойти до System Design.
2. Посмотреть на холст: логотип-арка + «To move canvas…», тулбара нет.
3. Попробовать соединить блоки стрелкой — инструмент не доступен.

## Корневая причина

Excalidraw 0.18 в контейнере шириной ≈768px (совпадает с
`dockedSidebarBreakpoint`) рендерит тулбар в свёрнутом «docked»-состоянии:
видимый элемент — `sidebar-trigger` (логотип, клик открывает sidebar),
а реальный тулбар (`Island.App-toolbar`, 12 ToolIcon) — скрыт.
Кандидату не очевидно, что логотип — кликабельный триггер.

## Фикс

`ExcalidrawCanvas.tsx` + `index.css`:

1. `UIOptions={{ dockedSidebarBreakpoint: 0 }}` — всегда desktop-раскладка.
2. CSS: принудительно видим `Island.App-toolbar`, скрыты
   `sidebar-trigger`, `HintViewer` (английские подсказки) и welcome-декор —
   русская 3-шаговая инструкция над палитрой объясняет процесс.
3. Холст 540→640px, чтобы весь вертикальный тулбар помещался.

Проверено (headless Chromium, `/tmp/grade-qa/qa-design-ux.mjs`):
тулбар виден (12 инструментов), триггер и подсказки скрыты, блоки
ставятся, «Очистить холст» работает, «Оценить схему» → PNG + ИИ-ревью.
