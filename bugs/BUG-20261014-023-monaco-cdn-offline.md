# BUG-20261014-023 — Редактор Live-Code зависит от CDN; светлая вспышка темы

**Симптом.** CodeEditor (@monaco-editor/react) грузил Monaco с CDN jsdelivr —
в оффлайн/LAN-интервью (нет интернета) навечно «Загрузка редактора…».
Дополнительно: тема задавалась через options.theme, который обёртка
игнорирует — проп theme по умолчанию «light» → редактор вспыхивал светлой
темой в тёмном кабинете (f02-livecode-task.png до фикса).

**Причина.** loader без конфига → CDN; theme проп не передан.

**Фикс.** Самохостинг: min/vs из пакета monaco-editor (уже в зависимостях)
скопирован в public/monaco/vs (14 МБ), `loader.config({ paths: { vs:
'/monaco/vs' } })`; тема передана пропом `theme="vs-dark"`.

**Проверено.** E2E с заблокированными jsdelivr/unpkg/cdnjs: Monaco смонтировался
локально, ошибок нет; редактор тёмный с первого кадра.
